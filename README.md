# Paradoxos Inexoráveis

**Idealização:** Aldenir Rocha de Oliveira Filho · Projeto 360X Brasil.

Site público em português sobre saúde, recursos, defesa, mercados e memória RAM. O conteúdo parte do material fornecido pelo autor, com estimativas declaradas, limites metodológicos e um simulador de cenários.

## Conteúdo

- Proposta ilustrativa de unidades de terapia intensiva e centros de cuidado ao neurodesenvolvimento.
- Comparação de ordens de grandeza entre implantação, custeio e referências de gastos anuais.
- Distinção entre valor de mercado e recursos disponíveis.
- Seção sobre memória RAM reproduzindo a abordagem do material de origem.
- Simulador com parâmetros editáveis e exportação de cenários.
- Referências, premissas e limitações.

## Publicação

Arquivo principal: `index.html`. O site não requer servidor de aplicação, instalação de dependências ou cadastro de visitantes.

Endereço previsto no GitHub Pages, após a ativação e implantação:

https://aldenirfilho.github.io/PARADOXOS-INEXORAVEIS/

A existência deste repositório não comprova que o GitHub Pages já esteja ativo.

Para publicar pela branch: **Settings → Pages → Deploy from a branch → main → /(root) → Save**.

## Limites

Os valores são cenários ilustrativos do material fornecido; esta edição não constitui auditoria independente das estatísticas, orçamento executivo, protocolo clínico ou recomendação de investimento. Quantidades de unidades não comprovam cobertura assistencial efetiva. Estoque patrimonial não equivale a caixa disponível, e projeções não devem ser tratadas como despesas já realizadas.
